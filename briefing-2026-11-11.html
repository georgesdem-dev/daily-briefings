🌟 Top Story: Record 1,094-Flaw Patch Tuesday Headlined by Actively Exploited Outlook Zero-Day CVE-2026-124194 · CISA KEV DEADLINE NOV 24

Microsoft's November Patch Tuesday addressed 1,094 vulnerabilities — the second-largest monthly release on record, with 63 rated Critical — across Windows 10/11, Windows Server 2016–2025, Office, Exchange Server Subscription Edition, Edge, and the Malware Protection Engine. The headline fix is CVE-2026-124194, an Outlook flaw (CVSS 6.5) that discloses a victim's NTLMv2 authentication hash when a malicious file is opened, letting attackers impersonate the user; Microsoft confirmed active exploitation, and CISA added it to the KEV catalog on Nov 10 with a November 24 remediation deadline. A second, more concerning issue remains unpatched: "SignDrop," a Windows privilege-escalation zero-day with public exploit code abusing the CLFS logging driver — a component with a history of ransomware abuse (10 prior CLFS flaws have appeared in CISA's KEV) — to gain SYSTEM access. As of today Microsoft has not assigned it a CVE or confirmed in-the-wild attacks. Separately, Google shipped an emergency Chrome update for CVE-2026-125350, a high-severity use-after-free already exploited in the wild — the eighth actively exploited Chrome zero-day of 2026.
