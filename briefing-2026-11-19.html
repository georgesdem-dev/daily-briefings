Critical CVE Java4Shell (CVE-2026-114938): Pre-Auth RCE in Java 17–27 — Active Scanning Begins

What it is: A memory corruption bug in OpenJDK's Base64 handling (Java 17.0.6+ and Java 21, 25, 27) allows an unauthenticated remote attacker to corrupt heap memory and achieve remote code execution. Dubbed "Java4Shell" for its Log4Shell-esque blast radius, it requires x86-64 processors with AVX-512 VBMI support (most modern Intel/AMD server CPUs; ARM not affected).

Affected applications (default-config, no login needed): Keycloak, Atlassian Jira, Atlassian Confluence, JFrog Artifactory, Jenkins, PingFederate. Additional apps (login required): Apache Kafka, Solr, Elasticsearch, Gerrit, Spinnaker.

Exploitation status: As of 6 AM ET today, GreyNoise recorded 150+ requests matching Java4Shell attack signatures from 5 IP addresses. No confirmed in-the-wild RCE yet — researchers are withholding full exploits while organizations patch. Oracle and OpenJDK released patches on November 17.
