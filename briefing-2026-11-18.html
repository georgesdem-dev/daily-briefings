🌟 Top Story: Unpatched Windows SignDrop Zero-Day Goes Public as "The Gentlemen" Claim an Unverified NVIDIA Breach NO MICROSOFT FIX AVAILABLE · UNVERIFIED NVIDIA CLAIM

Researcher "MSNightmare" published public exploit code and a detailed writeup for "SignDrop," a new Windows zero-day that abuses CLFS log authentication to gain local SYSTEM privilege escalation — Microsoft has not confirmed the flaw, assigned a CVE, or released a fix, leaving defenders without an official patch. This follows Tuesday's record 1,093-vulnerability Patch Tuesday, which included an actively exploited Outlook spoofing flaw letting attackers leak authentication data via a crafted message file. Google's Chrome use-after-free zero-day (CVE-2026-125350) — the eighth Chrome zero-day patched this year — was added to CISA's KEV catalog on November 10 with a November 24 federal deadline. On the ransomware front, "The Gentlemen" RaaS group listed NVIDIA on its dark-web leak site, showing revenue figures and a Tox negotiation ID but no sample files or proof of what was taken; NVIDIA has not confirmed a breach. The listing lands amid a sharp ransomware spike — Ransom-DB recorded 301 confirmed double-extortion incidents in the past week, up 56 from the week before. Separately, a newly disclosed "Java4Shell" flaw allows unauthenticated remote code execution across Jira, Jenkins, Keycloak and three other widely used applications, and Microsoft's own `agent-framework` PyPI package (versions 1.26.1–1.26.2) was found stealing Azure, Azure DevOps, and GitHub Actions credentials on startup.
