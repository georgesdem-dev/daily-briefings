Week of September 17–21, 2026
🌟 Top Story: Plugin4Shell — Zero-Click RCE Hits Four Major AI Coding Agents CRITICAL · SUPPLY CHAIN

Disclosed Sep 17 (reported to vendors in June), Plugin4Shell is a zero-click RCE affecting Claude Code, OpenAI Codex, GitHub Copilot, and Google Gemini CLI. Affected agents request a pinned plugin commit but fail to verify the checked-out working tree actually matches that SHA — letting an attacker who controls a trusted plugin repo exploit Git reference resolution to silently swap in a malicious branch while appearing to honor the pin. Installed plugins inherit the developer's full permissions: local source code, cloud credentials, SSH keys, internal repos, production systems, secrets. No user click, approval, or reinstall required.
