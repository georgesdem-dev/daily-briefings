Cybersecurity
Thursday, November 5, 2026
🌟 Top Story: Zyxel's Patch Fails to Stop the Zero-Day That Already Hit Nearly 1,000 Switches 10 GS1900 MODELS AFFECTED · ROOT COMMAND EXECUTION

Researchers at Binarly found that Zyxel's earlier fix for an actively exploited flaw in its GS1900 network switches does not actually block the exploit attackers have been using. The underlying vulnerability, CVE-2026-107441, is an out-of-bounds write that lets an unauthenticated attacker execute arbitrary OS commands via crafted HTTP requests, and it has already been used to compromise nearly 1,000 devices worldwide across ten affected GS1900 models. The episode is the second consecutive failed-patch cycle for this bug, raising the bar for how long defenders should assume a "fixed" network device is actually safe to leave exposed.
