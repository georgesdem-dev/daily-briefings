🔴 Citrix NetScaler Zero-Day Exploited In The Wild CRITICAL · CVE-2026-88779

Citrix released emergency patches for CVE-2026-88779 (CVSS 8.7), a memory overflow vulnerability in NetScaler ADC and NetScaler Gateway that can knock SAML-authenticated deployments offline. The flaw is being actively exploited in targeted attacks. CISA added it to the Known Exploited Vulnerabilities (KEV) catalog with a federal patch deadline of October 7, 2026. Organizations still running unpatched NetScaler appliances are exposed immediately — particularly those using SAML SSO for VPN or remote access.

→ The Hacker News

🔴 FortiMail Critical Bug Under Active Exploitation CRITICAL · CVE-2026-104286 · CVSS 9.8

CISA is warning of active exploitation of a critical flaw in Fortinet FortiMail (CVE-2026-104286, CVSS 9.8) that allows unauthenticated attackers to write arbitrary files on the underlying system — effectively leading to full system compromise. FortiMail is widely deployed as an enterprise email security gateway; organisations with internet-exposed FortiMail instances should treat this as an emergency patch.

→ The Hacker News: Weekly Recap

🟠 Microsoft Exchange Server Zero-Day (OWA XSS) HIGH · CVE-2026-42897

Microsoft confirmed a zero-day XSS spoofing vulnerability (CVE-2026-42897) affecting Exchange Server 2016, 2019, and SE's Outlook Web Access. An attacker can send a specially crafted email; if the victim opens it in OWA, arbitrary JavaScript executes in their browser — enabling session hijacking, credential theft, or phishing pivots. Microsoft's October Patch Tuesday (which is notably light — just 1 CVE, CVE-2026-96940, an EoP rated CVSS 8.8) also addressed this Exchange EoP. Both should be applied immediately.
