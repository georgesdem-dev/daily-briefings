🔴 Critical

FortiMail CVE-2026-104286 (CVSS 9.8) — Unauthenticated File Write, Actively Exploited

Fortinet disclosed CVE-2026-104286 on October 1st after confirming in-the-wild exploitation. The flaw — a path traversal combined with improper NULL byte handling in FortiMail — allows an unauthenticated attacker to write arbitrary files to the appliance via crafted HTTP/HTTPS requests, enabling full remote code execution. CISA set an emergency patch deadline for FCEB agencies of October 4th.

eSentire and The Hacker News confirmed multiple threat actors are actively using the vulnerability against email security gateways. The attack chain is trivial to execute once the appliance is internet-facing — no authentication required.

Immediate action: Patch all FortiMail instances now. If patching is delayed, take the appliance off the public internet. Review logs for unexpected file creation in /tmp and /var paths.

Source: The Hacker News · eSentire Advisory · Tech-Insider

NetScaler Third Zero-Day CVE-2026-88779 + Prior Backdoor Persistence

Citrix confirmed a third zero-day in NetScaler ADC/Gateway this cycle: CVE-2026-88779 (CVSS 8.7), a denial-of-service flaw that can knock SAML authentication deployments offline — disrupting VPN, SSO, and enterprise access infrastructure at the worst possible time. Immediate action: Do not assume patching removes persistence. Run Mandiant's NetScaler forensic scanner. Look for new admin accounts, unexpected cron entries, and memory-resident implants.
