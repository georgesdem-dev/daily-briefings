🌟 Top Story: China-Linked "Armory Castle" Exploited a VMware vCenter Zero-Day Since September to Hijack Admin Accounts EXPLOITED SINCE SEPTEMBER · CVSS 9.8

A suspected China-nexus espionage group tracked as Armory Castle has been exploiting a critical VMware vCenter zero-day, CVE-2026-123890 (CVSS 9.8), since at least early September — nearly two and a half months before Broadcom patched it on November 19 in advisory VMSA-2026-0009, alongside four other flaws affecting VMware SDDC Manager and VMware Tools for Windows. The flaw sits in VMware Directory Service and lets remote, unauthenticated attackers obtain an administrator-level authenticated session. The group's initial entry came through a separate zero-day, CVE-2026-102764, in BeyondTrust Remote Support, which it then chained into vCenter using a custom tool called Bonesaw — stealing the Lightning Memory-Mapped Database, extracting SAML signing material, and creating a rogue single sign-on administrator account to maintain persistent, stealthy access across victim environments. Separately, researchers disclosed FastUnlock (CVE-2026-126714), an unpatched Windows technique letting anyone with physical access to a locked computer launch programs without signing in, and a Linux KVM hypervisor flaw (CVE-2026-99312) affecting AMD hosts with nested virtualization enabled let researchers read roughly 127GB of a cloud server's memory from inside a guest VM.
