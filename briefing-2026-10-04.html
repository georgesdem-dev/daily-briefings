⚡ Critical Zero-Day FortiMail CVE-2026-104286 (CVSS 9.8) Actively Exploited — No Patch Available — CISA KEV Deadline: TODAY
This is the most urgent item in this briefing. Fortinet disclosed CVE-2026-104286, a path traversal + null-byte injection flaw in FortiMail (CVSS 9.8) that allows any unauthenticated internet attacker to write arbitrary files to the mail gateway — no credentials, no API token, no prior access required. Affected versions: FortiMail 7.2.0–7.2.9, 7.4.0–7.4.8, 7.6.0–7.6.6, 8.0.0–8.0.1. Active exploitation confirmed in the wild; no patch is yet available. CISA added it to the KEV catalog October 1 — the federal civilian agency deadline to mitigate is October 4, 2026 (today). Fortinet workarounds: (1) Disable the IBE (Identity-Based Encryption) feature, (2) Block internet access to the FortiMail management interface.

Impact: Attackers can disable mail scanning, exfiltrate archived communications, install persistent backdoors, or pivot into the broader network.
