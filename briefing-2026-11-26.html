🚨 Outlook Zero-Day CVE-2026-124194 — NTLM Hash Theft, Actively Exploited
Microsoft's November 2026 Patch Tuesday (1,094 CVEs — record release) included a critical fix for CVE-2026-124194, an Outlook spoofing flaw already under active exploitation. The attack vector is deceptively simple: an unauthenticated attacker sends a specially crafted message file; when the victim opens it, Outlook silently connects to an attacker-controlled server, leaking the user's NTLMv2 hash. That hash can then be used to impersonate the victim across the network. CISA has added it to the Known Exploited Vulnerabilities (KEV) catalog with an urgent remediation directive.

⚠️ Important: The fix ships in Office updates, not Windows updates. Organizations that patch only Windows remain exposed. Patch via File → Account → Update Options in Outlook.
